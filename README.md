# T-Invest Bot

Проект для наблюдения за опубликованными сделками авторов Пульса. Локальная админка запускает мониторинг через отдельный авторизованный браузер, показывает инструменты и новые операции. Опциональное автоисполнение в демо-режиме рассчитывает условные покупки и продажи по лимитам, ведёт отдельный демо-портфель и объясняет пропущенные сигналы. Код не подключается к брокерскому счёту и не выставляет реальные заявки.

## Текущий прототип

`pulse_replay.py` проверяет обработку снимков сделок без доступа к аккаунту. Первый счётчик по каждой бумаге становится исходной точкой. Если счётчик вырос, прототип берёт соответствующее число новых записей из начала истории; уменьшение счётчика или неполная история вызывают ошибку. Состояние сохраняется локально, поэтому повторная подача снимка не создаёт повторных событий.

```powershell
python pulse_replay.py --state .local/pulse-count-state.json fixtures/pulse-first.json
python pulse_replay.py --state .local/pulse-count-state.json fixtures/pulse-next.json
python pulse_replay.py --state .local/pulse-count-state.json fixtures/pulse-next.json
```

Ожидается: первый запуск — 0 новых событий; второй — 2 (две одинаковые по времени и цене операции); третий — 0. `fixtures/` содержат вымышленные данные в форме наблюдаемых полей Пульса. Это офлайн-прототип: стабильность счётчика, полнота истории и работа с авторизованным источником ещё не подтверждены.

## Админка и реальный мониторинг

Нужен Python 3.10+, установленный Brave, Edge или Chrome. На компьютере клиента сначала запусти [install.cmd](install.cmd): он создаст локальное `.venv` и установит зависимости, не затрагивая системный Python. Затем запускай [start_admin.cmd](start_admin.cmd). Альтернативно из корня репозитория:

```powershell
python -m pip install -r requirements.txt
python demo_admin.py
```

На Windows для входа через Пульс запусти [start_admin.cmd](start_admin.cmd) двойным щелчком из проводника. Он поднимает сервер в обычной консоли твоего рабочего стола, чтобы отдельное окно банка было видно. Консоль оставь открытой на время мониторинга. Если Python установлен не в стандартном каталоге, задай `T_INVEST_PYTHON` как полный путь к `python.exe`.

Открой `http://127.0.0.1:8765/`. Админка доступна сразу; подключение Пульса показано отдельным окном поверх панели, которое можно закрыть. Настройки и ручное демо работают до подключения источника. Нажми «Открыть окно Пульса» и войди в Т-Банк в отдельном окне Brave. После входа нажми «Проверить вход»: монитор сам переведёт **существующую** вкладку на сделки выбранного профиля. Повторно открывать вкладки не нужно. Обычный профиль Brave и окно мониторинга хранят входы раздельно. После успешного чтения сделок локальный сеанс и его cookie сохраняются в `.local/pulse-browser/`, которая исключена из Git. Если Т-Банк завершил сеанс, потребуется войти снова.

Одновременно может работать только одна копия админки на порту 8765. Повторный запуск сообщает, что порт занят, и не открывает второй монитор с другой авторизацией.

«Обзор» показывает источник и демо-результат, сделки автора за последние 24 часа, инструменты и состояние Telegram-бота с ID получателя. «Настройки» содержат профиль, интервал, режим, лимиты по акциям, облигациям, фондам и фьючерсам, Telegram и паузу; «Журнал» хранит сигналы, решение и причину. Кнопка «Купить · демо» рассчитывает условную покупку опубликованной акции не старше 24 часов. Режим «Мониторинг» включает чтение новых сделок и, по отдельному переключателю, их демо-обработку. При продаже проверяется только **условная демо-позиция**, не реальный счёт. Ручная проверка сценария доступна в режиме «Демо» даже без входа в Пульс. Токен Telegram можно указать в настройках или через `TELEGRAM_BOT_TOKEN`; при пустом ID сетевого запроса нет. Журнал, настройки и демо-портфель сохраняются в `.local/`.

Размер лота реальной акции в ответе Пульса отсутствует. При демо-обработке живого сигнала расчёт для акции использует **условный лот из одной акции** и отмечает это в событии. Для фьючерсов без данных о гарантийном обеспечении заявка блокируется. Эти расчёты не подходят для реальной торговли без данных брокера и согласованных лимитов. Опрос 3–5 секунд и расписание не входят в текущую версию; AnyDesk нужен владельцу проекта для установки на компьютере клиента.

Мониторинг читает внутренний веб-интерфейс Пульса, для которого нет документированного публичного API. Его формат и доступность могут измениться. Панель показывает весь полученный список инструментов, историю выбранного инструмента по страницам и новые операции после включения. Подробности и ограничения — в [сверке с ТЗ](docs/STATUS.md).
