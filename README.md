# T-Invest Bot

Проект для наблюдения за опубликованными сделками выбранных авторов в Пульсе и последующего исполнения собственных правил через T-Invest API. На 3 октября 2026 года репозиторий начинался пустым. Сейчас это документация и безопасный прототип обработки **нормализованных снимков** сделок. Подключения к Пульсу, Telegram и брокерскому счету ещё нет; реальные заявки код не выставляет.

## Текущий прототип

`pulse_replay.py` проверяет обработку снимков сделок без доступа к аккаунту. Первый снимок становится исходной точкой; при следующих запусках новые `id` выводятся как события. Состояние сохраняется локально, поэтому повторная подача снимка не создаёт повторных событий.

```powershell
python pulse_replay.py --state .local/pulse-state.json fixtures/pulse-first.json
python pulse_replay.py --state .local/pulse-state.json fixtures/pulse-next.json
python pulse_replay.py --state .local/pulse-state.json fixtures/pulse-next.json
```

Ожидается: первый запуск — 0 новых событий; второй — 1; третий — 0. `fixtures/` содержат вымышленные данные. Формат этих файлов — **внутренний контракт прототипа**, не утверждение о формате API Пульса.
