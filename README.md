# T-Invest Bot

Проект для наблюдения за опубликованными сделками авторов Пульса. Локальная админка запускает мониторинг через отдельный авторизованный браузер, показывает инструменты и новые операции. Опциональная «авто-покупка» создаёт только демо-запись; код не подключается к брокерскому счёту и не выставляет реальные заявки.

## Текущий прототип

`pulse_replay.py` проверяет обработку снимков сделок без доступа к аккаунту. Первый счётчик по каждой бумаге становится исходной точкой. Если счётчик вырос, прототип берёт соответствующее число новых записей из начала истории; уменьшение счётчика или неполная история вызывают ошибку. Состояние сохраняется локально, поэтому повторная подача снимка не создаёт повторных событий.

```powershell
python pulse_replay.py --state .local/pulse-count-state.json fixtures/pulse-first.json
python pulse_replay.py --state .local/pulse-count-state.json fixtures/pulse-next.json
python pulse_replay.py --state .local/pulse-count-state.json fixtures/pulse-next.json
```

Ожидается: первый запуск — 0 новых событий; второй — 2 (две одинаковые по времени и цене операции); третий — 0. `fixtures/` содержат вымышленные данные в форме наблюдаемых полей Пульса. Это офлайн-прототип: стабильность счётчика, полнота истории и работа с авторизованным источником ещё не подтверждены.

## Админка и реальный мониторинг

Нужен Python 3.10+, установленный Brave, Edge или Chrome. Из корня репозитория:

```powershell
python -m pip install -r requirements.txt
python demo_admin.py
```

Открой `http://127.0.0.1:8765/`. До входа виден экран авторизации. Нажми «Открыть окно Пульса», в отдельном окне Brave нажми **«Войти»** и затем открой «Сделки» выбранного профиля. Обычный профиль Brave и окно мониторинга хранят входы раздельно. Когда монитор прочитает список сделок, админка откроет «Обзор». Если сделки видны в отдельном окне, а админка всё ещё ждёт, нажми «Проверить вход» — это обновит существующую страницу без нового окна. Для живого мониторинга окно Пульса остаётся открытым; его можно свернуть. Сеанс сохраняется в `.local/pulse-browser/`, которая исключена из Git. Если вход действует после перезапуска, экран авторизации пропускается.

«Обзор» показывает график, сделки автора за последние 24 часа, инструменты и демо-результат. «Настройки» содержат профиль, интервал, режим, Telegram и паузу; «Журнал» хранит сигналы. Кнопка «Купить · демо» создаёт запись для опубликованной покупки акции не старше 24 часов. Режим «Реальная работа» включает живой мониторинг, но не брокерские заявки. Ручная проверка сценария доступна в режиме «Демо». Токен Telegram можно указать в настройках или через `TELEGRAM_BOT_TOKEN`; при пустом ID сетевого запроса нет. Журнал и настройки сохраняются в `.local/`.

Мониторинг читает внутренний веб-интерфейс Пульса, для которого нет документированного публичного API. Его формат и доступность могут измениться. Панель показывает весь полученный список инструментов, историю выбранного инструмента по страницам и новые операции после включения. Подробности и ограничения — в [сверке с ТЗ](docs/STATUS.md).
