# T-Invest Bot

Проект для наблюдения за опубликованными сделками авторов Пульса. Локальная админка запускает мониторинг через отдельный авторизованный браузер, показывает инструменты и новые операции. Симуляция ведёт отдельный условный портфель. Реальные лимитные заявки через официальный T-Invest API доступны отдельным режимом: с подтверждением каждой заявки или автоматически по заданным лимитам. По умолчанию реальная торговля выключена.

## Текущий прототип

`pulse_replay.py` проверяет обработку снимков сделок без доступа к аккаунту. Первый счётчик по каждой бумаге становится исходной точкой. Если счётчик вырос, прототип берёт соответствующее число новых записей из начала истории; уменьшение счётчика или неполная история вызывают ошибку. Состояние сохраняется локально, поэтому повторная подача снимка не создаёт повторных событий.

```powershell
python pulse_replay.py --state .local/pulse-count-state.json fixtures/pulse-first.json
python pulse_replay.py --state .local/pulse-count-state.json fixtures/pulse-next.json
python pulse_replay.py --state .local/pulse-count-state.json fixtures/pulse-next.json
```

Ожидается: первый запуск — 0 новых событий; второй — 2 (две одинаковые по времени и цене операции); третий — 0. `fixtures/` содержат вымышленные данные в форме наблюдаемых полей Пульса. Авторизованное чтение списка и истории проверено на LinMath 03.10.2026; обнаружение новой сделки в момент её публикации и стабильность счётчика ещё не проверены.

## Админка и реальный мониторинг

Нужен Python 3.10+, установленный Brave, Edge или Chrome. На компьютере клиента сначала запусти [install.cmd](install.cmd): он создаст локальное `.venv` и установит зависимости, не затрагивая системный Python. Затем запускай [start_admin.cmd](start_admin.cmd). Альтернативно из корня репозитория:

```powershell
python -m pip install -r requirements.txt
python demo_admin.py
```

На Windows для входа через Пульс запусти [start_admin.cmd](start_admin.cmd) двойным щелчком из проводника. Он поднимает сервер в обычной консоли твоего рабочего стола, чтобы отдельное окно банка было видно. Консоль оставь открытой на время мониторинга. Если Python установлен не в стандартном каталоге, задай `T_INVEST_PYTHON` как полный путь к `python.exe`.

Открой `http://127.0.0.1:8765/`. Админка доступна сразу; подключение Пульса показано отдельным окном поверх панели, которое можно закрыть. Настройки доступны до подключения источника; для ручной условной покупки нужны опубликованные сделки автора. Нажми «Открыть окно Пульса» и войди в Т-Банк в отдельном окне Brave. После входа нажми «Проверить вход»: монитор сам переведёт **существующую** вкладку на сделки выбранного профиля. Повторно открывать вкладки не нужно. Обычный профиль Brave и окно мониторинга хранят входы раздельно. После успешного чтения сделок локальный сеанс и его cookie сохраняются в `.local/pulse-browser/`, которая исключена из Git. Если Т-Банк завершил сеанс, потребуется войти снова.

Одновременно может работать только одна копия админки на порту 8765. Повторный запуск сообщает, что порт занят, и не открывает второй монитор с другой авторизацией.

«Обзор» показывает источник, условный результат и отдельную сводку реального счёта, сделки автора за последние 24 часа, инструменты и состояние Telegram-бота с ID получателя. В строках опубликованных покупок акций, облигаций и фондов можно повторить покупку: в обычном режиме условно, в торговом — через проверку и подтверждение реальной заявки. Кнопка автокопирования относится только к симуляции; реальный автоматический режим выбирается отдельно в настройках. Ранее опубликованные сделки автоматически не исполняются. «Журнал» хранит сигналы, решения и ошибки. При пустом Telegram ID сетевого запроса на отправку нет. Данные сохраняются в `.local/`.

Кнопка «Посмотреть за месяц» в блоке сделок загружает опубликованные операции за последние 30 дней по требованию. Панель показывает ход загрузки по инструментам. Сделки старше 24 часов доступны только для просмотра; месячный архив не создаёт брокерских заявок и не меняет правила автокопирования новых сделок.

## Подключение брокерского счёта

1. В личном кабинете Т-Инвестиций создай токен API **только для чтения**. [Официальная инструкция T-Банка](https://developer.tbank.ru/invest/intro/intro/token). Разреши ему доступ к нужному брокерскому счёту. Токен с полным доступом админка отклонит.
2. В админке открой «Настройки» → «Брокерский счёт», вставь токен и нажми «Подключить». Если счетов несколько, выбери нужный в списке. «Обновить счёт» повторно загружает остаток и позиции.
3. Токен сохраняется в `.local/broker-read-token.txt`, выбор счёта — в `.local/broker-account.txt`. Они исключены из Git. Можно вместо файла задать переменную среды `TINVEST_READ_TOKEN`. Не отправляй токен в чат и не записывай его на видео.

Подключение счёта работает отдельно от входа в Пульс. Демо-портфель не смешивается с реальными позициями. Этот токен по-прежнему допускает только чтение. Проверка на реальном счёте требует токена владельца; в репозитории выполнены проверки на тестовых ответах.

## Реальные покупки и продажи

1. В кабинете Т-Инвестиций создай **отдельный API-токен с полным доступом** к нужному открытому брокерскому счёту ([виды токенов](https://developer.tbank.ru/invest/intro/intro/token)). Вставь его в «Настройки» → «Реальные заявки» и нажми «Проверить токен». Выбери нужный счёт. Токен сохраняется локально в `.local/broker-trade-token.txt`, выбор счёта — в `.local/trade-account.txt`; в Git они не попадают. Не присылай токен в чат.
2. Проверь лимиты по каждому классу активов, Telegram ID и кнопку «Проверить отправку». Включи мониторинг. В поле «Реальная торговля» выбери «Подтверждать каждую заявку» или «Автоматически по лимитам» и сохрани настройки. Режим «Выключена» установлен изначально. Смена токена или торгового счёта выключает режим.
3. При ручном режиме новый сигнал ждёт решения в журнале. Покупку автора за последние 24 часа можно подготовить на обзоре. Перед отправкой появятся инструмент, лоты, лимитная цена и оценка суммы; при изменении цены или количества подготовку придётся повторить. В автоматическом режиме только **новые** сигналы Пульса после включения могут стать заявками. Уже видимые при первом подключении сделки служат исходной точкой.

Перед заявкой проверяются точные тикер и класс, UID, тип инструмента, доступность торговли через API, размер лота, свежий стакан, рублёвые средства/позиции, брокерский лимит покупок на собственные деньги, а для фьючерса — гарантийное обеспечение. Продажа ограничена фактически исполненными покупками этого бота и доступной позицией на счёте. Отправляются **лимитные** заявки по текущей встречной цене; фактическое исполнение и его цена могут отличаться от публикации автора. Заявка может остаться неисполненной; активные лимитные заявки вручную проверяй в приложении банка. Выключение режима не отменяет уже выставленную заявку.

Если денег или позиции недостаточно, заявка не отправляется: причина появляется в журнале и уходит в Telegram. Отклонение брокером, отмена и изменение исполненного количества также отражаются в журнале и Telegram. При сетевой ошибке после отправки статус считается неопределённым: повторная отправка той же сделки запрещена, пока заявка не сверена с брокером. Уведомления требуют указанного Telegram ID; при пустом ID они остаются только в панели. «Пауза уведомлений» отключает обычные сообщения, но важные ошибки реальных заявок всё равно отправляются. Для остановки новых реальных заявок выбери режим «Выключена».

Код и тесты готовы, но **заявка с настоящим токеном ещё не отправлялась**. Перед автоматическим режимом проверь ручную заявку на своём счёте с минимальными лимитами и её статус в приложении банка. Для облигаций и фьючерсов также нужна отдельная проверка фактического расчёта цены/ГО на конкретном инструменте.

Размер лота в ответе Пульса отсутствует. Симуляция использует условный лот из одной единицы; реальная торговля получает лот и ГО из API брокера. Опрос 3–5 секунд и расписание не входят в текущую версию; AnyDesk нужен владельцу проекта для установки на компьютере клиента.

Мониторинг читает внутренний веб-интерфейс Пульса, для которого нет документированного публичного API. Его формат и доступность могут измениться. Панель показывает весь полученный список инструментов, историю выбранного инструмента по страницам и новые операции после включения. Подробности и ограничения — в [сверке с ТЗ](docs/STATUS.md).
