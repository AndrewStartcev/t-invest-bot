# Доступ к данным Пульса: проверка на 03.10.2026

## Что опубликовано официально

В изученном [каталоге T-Invest API](https://developer.tbank.ru/invest/intro/intro/) нет документированного метода чтения сделок **чужого профиля Пульса**. T-Invest API предназначен для торговой платформы и данных собственного счёта; его read-only, full-access и sandbox токены имеют отдельные права ([виды токенов](https://developer.tbank.ru/invest/intro/intro/token)). Наличие T-Invest API токена не означает доступ к Пульсу.

[Справка Т-Банка о профиле Пульса](https://www.tbank.ru/invest/help/services/pulse/about/profile/) говорит, что зрителям показывают сделки и цену, но скрывают количество купленных/проданных бумаг. Там же указано, что видимость профиля зависит от его настроек. [Справка о чёрном списке](https://www.tbank.ru/invest/help/services/pulse/about/blacklists/) подтверждает, что заблокированный пользователь не видит сделки профиля.

## Что найдено в браузере

После входа на сайт страница [сделок LinMath](https://www.tbank.ru/invest/pulse/profile/LinMath/operations/) загрузила два внутренних JSON-запроса: список инструментов и историю операций по инструменту. Их пути и поля без данных сессии записаны в [PULSE_RESEARCH.md](PULSE_RESEARCH.md). Полный URL включает `sessionId`; это часть авторизованного веб-сеанса. Ответ истории не содержит ID и объёма операции.

Эти запросы **не входят в документированный T-Invest API**. Мы не нашли отдельный публичный ключ, OAuth-поток или сервисный доступ для чтения чужих сделок Пульса. Вывод относится к изученной документации и браузерному сценарию, а не к закрытым возможностям банка. Постоянный серверный мониторинг через веб-сеанс пока не подтверждён технически: сессия может истекать, доступ зависит от правил Пульса, лимиты/условия внутреннего интерфейса не опубликованы.

## Возможные режимы проекта

| Режим | Статус | Что нужно |
| --- | --- | --- |
| Локальная демонстрация на вымышленных событиях | Доступна | Без Пульса и брокерских токенов |
| Мониторинг во время активной авторизованной веб-сессии | Исследовательский | Проверить стабильность и допустимость, не хранить сессию в Git |
| Постоянный серверный мониторинг чужих сделок | Не подтверждён | Официальный/разрешённый способ авторизации и допустимая частота |
| Торговля своим счётом через T-Invest API | Отдельный этап | Токен нужного типа, правила и проверка в песочнице |

## Важное следствие для ТЗ

Публичная цена чужой сделки не сообщает её объём. Размер собственной заявки должен рассчитываться по настройкам клиента и состоянию его счёта; «точное копирование объёма» выполнить по этим данным нельзя. Также нельзя обещать мгновенное обнаружение до измерения задержки публикации.
