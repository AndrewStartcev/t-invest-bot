# Демо для записи клиенту

Админка читает Пульс после входа в отдельном браузере. Ручные сценарии работают и **без входа** — запись можно повторить в любое время. Ни один режим не создаёт брокерскую заявку. Демо-портфель хранится отдельно от реального счёта.

## Запуск

На Windows один раз запусти `install.cmd`, затем `start_admin.cmd` двойным щелчком; консоль должна оставаться открытой. Нужен Python 3.10+ и Brave, Edge или Chrome. Из корня репозитория альтернативно:

```powershell
python -m pip install -r requirements.txt
python demo_admin.py
```

Откройте `http://127.0.0.1:8765/`. Сервер принимает подключения только с этого компьютера. Настройки хранятся в `.local/demo-settings.json`, который исключён из Git.

## Сценарий записи, 2–3 минуты

1. Открой панель `http://127.0.0.1:8765/`. Если Пульс не подключён, закрой окно подключения крестиком: ручное демо доступно без входа. В «Настройках» нажми «Сбросить демо и тестовые записи». Это очистит условный портфель и записи ручных сценариев; события живого Пульса останутся в журнале.
2. Покажи редактируемые лимиты по акциям, облигациям, фондам и фьючерсам. Стартовые суммы из видео клиента — черновик, они ещё требуют подтверждения. Сохрани настройки.
3. В блоке «Проверка сценария» нажми «Продать свою акцию» **до** покупки. В сообщении и журнале появится «ДЕМО: пропущено» с причиной «Нет своей демо-позиции».
4. Нажми «Купить акцию · 500 ₽», затем «Продать свою акцию». Открой «Обзор»: там меняется число демо-операций и состояние условного портфеля. В «Журнале» видны объём и причина решения.
5. Нажми «Дорогая акция · 8 000 ₽»: один лот пройдёт, если его цена ниже отдельного лимита 15 000 ₽, несмотря на бюджет 5 000 ₽. Нажми «Фьючерс · ГО 27 000 ₽»: он будет пропущен при лимите обеспечения 10 000 ₽. Нажми «Фьючерс · ГО 9 000 ₽»: один контракт попадёт в демо-портфель; затем покажи его закрытие.
6. Для демонстрации источника войди в Т-Банк в отдельном окне, открываемом кнопкой «Подключить Пульс». После входа нажми «Проверить вход». В «Обзоре» покажи опубликованные сделки за 24 часа и инструменты; для покупки акции доступна кнопка «Купить · демо». При включённом «Мониторинге» и «Автоисполнении · демо» новые сигналы обрабатываются по лимитам. Сделка автора может не появиться во время записи, поэтому основной сценарий выше воспроизводится без ожидания.
7. Если собственный Telegram-бот и ID уже настроены, в блоке Telegram нажми «Проверить отправку». После успешной доставки статус станет «Работает», событие попадёт в журнал. Повтори ручной сценарий и покажи уведомление о решении. При пустом ID отправки нет.

## Настройка тестового Telegram

1. В Telegram откройте [@BotFather](https://t.me/BotFather), выполните `/newbot`, сохраните выданный токен **только у себя**. Официальная инструкция: [Telegram Bot Features](https://core.telegram.org/bots/features#creating-a-new-bot).
2. Откройте своего бота и нажмите **Start** — иначе личный чат для сообщений может быть недоступен.
3. Узнайте числовой ID своего чата из `message.chat.id` в ответе [`getUpdates`](https://core.telegram.org/bots/api#getupdates). Запрос выполняйте своим локальным инструментом; не вставляйте токен в URL браузера и не присылайте его в чат. Если у бота настроен webhook, `getUpdates` не сработает; в этом случае используйте уже известный ID или настройте получение обновлений отдельно.
4. В админке введите токен бота и числовой ID и сохраните. Токен хранится в локальном файле `.local/telegram-token.txt` и не возвращается браузеру. Альтернатива: перед запуском задать `$env:TELEGRAM_BOT_TOKEN = '<ваш токен>'`.
5. Нажмите кнопку демо-сигнала. Бот отправит текст с пометкой «ДЕМО» через [`sendMessage`](https://core.telegram.org/bots/api#sendmessage) только на указанный ID. Если ID пустой, отправки не будет.

## Проверки перед показом

- Токен Telegram и ID не нужны для шагов 1–5.
- Закройте реальные кабинеты и персональные данные на экране записи.
- Для записи клиенту используйте собственный тестовый бот и свой ID, не данные клиента.
- Включённый мониторинг запускает фоновый опрос, пока работает процесс админки. Для записи без ожидания чужой новой сделки используйте ручные тестовые кнопки.
