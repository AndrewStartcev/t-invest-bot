# Демо для записи клиенту

Админка читает Пульс после входа в отдельном браузере. Для показа используется опубликованная покупка автора за последние 24 часа. Ни ручное повторение, ни автокопирование не создают брокерскую заявку. Условный портфель хранится отдельно от реального счёта.

## Запуск

На Windows один раз запусти `install.cmd`, затем `start_admin.cmd` двойным щелчком; консоль должна оставаться открытой. Нужен Python 3.10+ и Brave, Edge или Chrome. Из корня репозитория альтернативно:

```powershell
python -m pip install -r requirements.txt
python demo_admin.py
```

Откройте `http://127.0.0.1:8765/`. Сервер принимает подключения только с этого компьютера. Настройки хранятся в `.local/demo-settings.json`, который исключён из Git.

## Сценарий записи, 2–3 минуты

1. Открой панель `http://127.0.0.1:8765/` и авторизуйся в Пульсе, если сохранённый вход закончился. В «Обзоре» дождись списка сделок автора за 24 часа.
2. Покажи редактируемые лимиты по акциям, облигациям, фондам и фьючерсам в «Настройках». Стартовые суммы из видео клиента ещё требуют подтверждения.
3. В «Сделках автора за 24 часа» найди опубликованную покупку акции, облигации или фонда и нажми «Повторить покупку». Результат появится в условном портфеле и журнале, с рассчитанным объёмом или причиной пропуска. Для одинаковой записи повторная успешная покупка недоступна.
4. Нажми «Включить автокопирование». Оно включает мониторинг новых публикаций и условно повторяет новые покупки и продажи по лимитам. При отсутствии своей условной позиции продажа пропускается. Для показа этого шага не нужно ждать новой сделки: статус включения и правила видны сразу, а фактическое событие появится только после новой публикации автора.
5. Покажи в «Настройках» подключённый брокерский счёт, если у тебя есть токен только для чтения. Реальные позиции и остаток находятся отдельно от условного портфеля. Брокерская заявка не отправляется.
6. Если Telegram-бот и ID настроены, в блоке Telegram нажми «Проверить отправку». При пустом ID отправки нет.

## Настройка тестового Telegram

1. В Telegram откройте [@BotFather](https://t.me/BotFather), выполните `/newbot`, сохраните выданный токен **только у себя**. Официальная инструкция: [Telegram Bot Features](https://core.telegram.org/bots/features#creating-a-new-bot).
2. Откройте своего бота и нажмите **Start** — иначе личный чат для сообщений может быть недоступен.
3. Узнайте числовой ID своего чата из `message.chat.id` в ответе [`getUpdates`](https://core.telegram.org/bots/api#getupdates). Запрос выполняйте своим локальным инструментом; не вставляйте токен в URL браузера и не присылайте его в чат. Если у бота настроен webhook, `getUpdates` не сработает; в этом случае используйте уже известный ID или настройте получение обновлений отдельно.
4. В админке введите токен бота и числовой ID и сохраните. Токен хранится в локальном файле `.local/telegram-token.txt` и не возвращается браузеру. Альтернатива: перед запуском задать `$env:TELEGRAM_BOT_TOKEN = '<ваш токен>'`.
5. Нажмите «Проверить отправку» в блоке Telegram. Бот отправит тест через [`sendMessage`](https://core.telegram.org/bots/api#sendmessage) только на указанный ID. Если ID пустой, отправки не будет.

## Проверки перед показом

- Токен Telegram и ID не нужны для шагов 1–5. Для ручной покупки нужна хотя бы одна опубликованная покупка за последние 24 часа.
- Закройте реальные кабинеты и персональные данные на экране записи.
- Для записи клиенту используйте собственный тестовый бот и свой ID, не данные клиента.
- Включённый мониторинг запускает фоновый опрос, пока работает процесс админки. Ручная покупка берёт реальную запись Пульса за 24 часа и симулирует исполнение.
