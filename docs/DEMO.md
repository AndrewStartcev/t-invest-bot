# Демо для записи клиенту

Админка теперь умеет читать Пульс в реальном времени после входа в отдельном браузере. Ручные тестовые кнопки остаются для повторяемой записи. Ни один режим не создаёт брокерскую заявку. На экране видна метка «ДЕМО» и пояснение об отсутствии реальных заявок.

## Запуск

Нужен Python 3.10+. Из корня репозитория:

```powershell
python -m pip install -r requirements.txt
python demo_admin.py
```

Откройте `http://127.0.0.1:8765/`. Сервер принимает подключения только с этого компьютера. Настройки хранятся в `.local/demo-settings.json`, который исключён из Git.

## Сценарий записи, 1–2 минуты

1. Откройте локальную панель. На экране входа нажмите «Открыть окно Пульса» и войдите в Т-Банк именно в этом отдельном окне браузера. Откройте «Сделки» профиля. Если админка ещё ждёт, нажмите «Проверить вход»: существующее окно обновится один раз. Окно Пульса нужно оставить открытым для мониторинга; его можно свернуть. Обычная сессия Brave не переносится в окно мониторинга.
2. После появления «Обзора» покажите график, список сделок автора за 24 часа и демо-результат. Для покупки акции автора за последние 24 часа нажмите «Купить · демо»: запись появится в журнале, без брокерской заявки.
3. В «Настройках» покажите профиль Пульса, интервал, поле Telegram ID и паузу. Сохраните настройки с пустым ID.
4. В режиме «Демо» нажмите «Тестовая покупка» в блоке «Проверка сценария». В журнале появится запись «не отправлено: ID не указан». Сетевой запрос к Telegram при пустом ID не создаётся.
5. Для живого сценария выберите «Реальная работа» и «Авто-покупка · демо», сохраните. Новая опубликованная покупка автора появится в журнале с результатом «ДЕМО: куплено». До публикации новой сделки пользуйтесь повторяемой проверкой сценария из режима «Демо».
6. При желании отдельно настройте собственного бота и свой ID, выключите паузу и запишите доставку **тестового** сообщения.

## Настройка тестового Telegram

1. В Telegram откройте [@BotFather](https://t.me/BotFather), выполните `/newbot`, сохраните выданный токен **только у себя**. Официальная инструкция: [Telegram Bot Features](https://core.telegram.org/bots/features#creating-a-new-bot).
2. Откройте своего бота и нажмите **Start** — иначе личный чат для сообщений может быть недоступен.
3. Узнайте числовой ID своего чата из `message.chat.id` в ответе [`getUpdates`](https://core.telegram.org/bots/api#getupdates). Запрос выполняйте своим локальным инструментом; не вставляйте токен в URL браузера и не присылайте его в чат. Если у бота настроен webhook, `getUpdates` не сработает; в этом случае используйте уже известный ID или настройте получение обновлений отдельно.
4. В админке введите токен бота и числовой ID и сохраните. Токен хранится в локальном файле `.local/telegram-token.txt` и не возвращается браузеру. Альтернатива: перед запуском задать `$env:TELEGRAM_BOT_TOKEN = '<ваш токен>'`.
5. Нажмите кнопку демо-сигнала. Бот отправит текст с пометкой «ДЕМО» через [`sendMessage`](https://core.telegram.org/bots/api#sendmessage) только на указанный ID. Если ID пустой, отправки не будет.

## Проверки перед показом

- Токен Telegram и ID не нужны для шагов 1–4.
- Закройте реальные кабинеты и персональные данные на экране записи.
- Для записи клиенту используйте собственный тестовый бот и свой ID, не данные клиента.
- Включённый мониторинг запускает фоновый опрос, пока работает процесс админки. Для записи без ожидания чужой новой сделки используйте ручные тестовые кнопки.
