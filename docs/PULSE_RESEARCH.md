# Пульс: журнал исследования

Дата: 03.10.2026. Проверка проведена на [публичном профиле LinMath](https://www.tbank.ru/invest/social/profile/LinMath/) без входа. Страница открылась, показала описание и вкладки «Посты»/«Ролики». Вкладка «Сделки» в этом сеансе не отображалась. Поэтому получить фактический запрос и структуру операций пока не удалось. В видеозаписи из предыдущего обсуждения вкладка «Сделки» и история по инструменту были видны; это наблюдение из прошлого чата, а не повторная проверка на текущей странице.

## Что требуется выяснить

| Вопрос | Состояние |
| --- | --- |
| Нужен ли вход для вкладки «Сделки» | Неизвестно; без входа вкладка не видна |
| URL и метод запроса списка инструментов | Неизвестно |
| URL и метод запроса истории инструмента | Неизвестно |
| Формат BUY/SELL, ID, время и цена | Неизвестно |
| Точность времени и задержка публикации | Неизвестно |
| Пагинация и лимиты | Неизвестно |

Нельзя считать посты автора подтверждением сделки: упоминание тикера в тексте не означает покупку или продажу.

## Как снять безопасный образец в своём браузере

1. Войдите на `tbank.ru` в своём браузере и откройте профиль, где видна вкладка **«Сделки»**. Скопируйте ссылку на профиль.
2. Нажмите `F12` → **Network / Сеть** → фильтр **Fetch/XHR**. Включите **Preserve log / Сохранять журнал** и очистите список запросов.
3. Откройте вкладку «Сделки». Найдите запрос, после которого появился список инструментов; затем нажмите на один инструмент и найдите запрос, после которого появилась история BUY/SELL.
4. Для каждого из двух запросов запишите: путь URL **без query-параметров с персональными данными**, метод, HTTP-статус, основные имена полей JSON и по одному **обезличенному** примеру элемента списка/операции. Можно сделать снимок экрана вкладки Preview/Response после закрытия личных данных.
5. Удалите из примеров `Authorization`, `Cookie`, `Set-Cookie`, `x-request-id`, токены, номера счёта, телефон, email, идентификаторы сессии и любые персональные данные. **Не используйте “Copy as cURL” и не отправляйте полный HAR** — они обычно содержат действующие cookie.
6. Пришлите ссылку на профиль, два очищенных JSON-фрагмента и укажите, видна ли вкладка без входа в другом окне браузера. Если не уверены, что данные очищены, пришлите только скриншот с замазанными значениями и названиями полей.

После этого можно написать адаптер к подтверждённому формату, измерить задержку и выбрать разумный интервал опроса. Обращение к внутреннему endpoint остаётся исследовательской гипотезой до проверки стабильности и допустимости использования.
