## Авторизация и источники

Мониторинг не использует T-Invest API: читает видимые сделки через внутренние запросы сайта Пульса в отдельном браузере. Для этого нужен обычный вход пользователя в Т-Банк в окне, которое открывает мониторинг. В существующий браузерный сеанс пользователя сервис не подключается. Cookie и данные входа остаются в `.local/pulse-browser/`; URL с `sessionId` держится только в памяти процесса и не выводится в интерфейс или лог.

T-Invest API понадобится для чтения собственного счёта и реальных покупок/продаж. Для реальных заявок нужен отдельный токен с соответствующими правами и правила риска. На этом этапе токен T-Invest не нужен.

Пульс скрывает объём чужой сделки; точное копирование количества невозможно по показанным данным. При истечении входа сервис показывает ошибку и ждёт повторного входа. Поскольку это внутренний веб-интерфейс, стабильность, допустимая частота и задержка публикации не гарантированы.

Во время локальной проверки 03.10.2026 в отдельном профиле открывалась страница LinMath, но наблюдался только запрос `profile/lite`, без списка инструментов. На странице оставались кнопки «Создать профиль» и «Войти». Поэтому авторизованное чтение сделок в этой сборке пока не подтверждено. Проверку продолжит владелец в своём окне; до успешного списка панель остаётся на экране входа.
