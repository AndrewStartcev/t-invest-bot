Пульс читается через авторизованный браузер, без официального API для сделок чужого профиля. Обычный вход в Т-Банк хранится в .local/pulse-browser/. Отдельный токен только для чтения показывает собственный счёт; токен с полным доступом нужен лишь для реальных заявок и хранится локально. Объём чужой сделки Пульс не показывает, поэтому объём нашей заявки рассчитывается по собственным лимитам и данным брокера.

Проверены автоматические тесты на подставных ответах брокера, в том числе недостаток средств, ограничение продажи, частичное исполнение и отсутствие повторной отправки после сетевой ошибки. Живой пилот на минимальной сумме и сверка с приложением банка ещё нужны. Лимитная заявка может остаться в стакане после выключения режима; её отменяют отдельно в приложении банка.

## Изменения 05.10.2026

- Ссылки выпуска обоих токенов ведут на `https://www.tbank.ru/invest/settings/api/`; API брокера использует `invest-public-api.tbank.ru`. Пульс остаётся на `www.tbank-online.com`.
- При обновлении старые настройки автоматически получают отдельные лимиты продаж, сохраняя прежнюю долю закрытия. Рублёвые ограничения продаж теперь обязательны; проверь их перед включением торговли.
- В расчёте продажи целые лоты округляются вниз: 25% от одного лота не превращаются в продажу всего лота. Продажа облигаций учитывает НКД, фьючерсов — освобождаемое ГО длинной позиции. Сторонние покупки на счёте по-прежнему не продаются ботом.
- Собственный портфель обновляется независимо от подключения Пульса; при ошибке видны время последнего снимка и предупреждение об устаревших данных. Смена счёта во время запроса не подменяет его снимок.

## Изменения 06.10.2026

- Окно подключения Пульса и кнопки входа скрыты уже в исходном HTML: клиентский общий источник не показывает вспышку окна до получения настроек. Ошибка начальной загрузки выводится отдельно. Добавлен возврат ошибочного пути `/source-admin/https://invest.argokov.ru/source-admin/` на фиксированный `/source-admin/` после проверки доступа владельца; внешние адреса не перенаправляются. Источник первоначальной склейки URL после ввода кода пока не подтверждён; публичная проверка исходной страницы получила 401 без заголовка Location.

- Добавлен серверный режим общего источника: владелец авторизует свой банк на `/source-admin/` с отдельным паролем `source-owner`, клиент использует основной `admin` только для настроек и своих API-токенов. Клиентский интерфейс не требует входа в банк; сервер блокирует команды входа и защищает noVNC паролем владельца. Скрипт `configure_shared_source.sh` выполняет переключение. Это по-прежнему одна установка для одного клиента, без многопользовательской изоляции. API-токены и банковские cookies остаются на сервере; живое переключение и авторизацию проверяет владелец.

- Журнал сервера подтвердил ошибку `Openbox-Message: Invalid command line argument "--display"`: менеджер окон постоянно завершался, а зависимые VNC/noVNC перезапускались. Удалён недопустимый аргумент; экран задаётся через существующий `Environment=DISPLAY=:99`. Стабильность сервисов и клавиатуру после исправления проверяет владелец на сервере.
- После исправления временного каталога владелец подтвердил открытие формы входа через noVNC, но сообщил об отсутствии ввода с клавиатуры. Подготовлены явные параметры XKB/раскладки/разрешённого ввода и зависимость VNC от Openbox. Причина ещё не подтверждена журналом сервера; ввод после обновления нужно проверить у клиента.
- При первом запуске на Ubuntu 24.04 получен `EROFS` при создании `/tmp/playwright-artifacts-*`. Исправлен unit: временный каталог задаётся через `RuntimeDirectory`/`TMPDIR` и разрешён для записи. Живую проверку после обновления выполняет владелец на сервере.
- «Войти в Т-Банк» автоматически открывает окно noVNC у клиента, до асинхронного запроса; при блокировке всплывающего окна остаётся ручная ссылка. Файлы noVNC обслуживает nginx, WebSocket остаётся за тем же логином/паролем.
- Добавлен `TINVEST_PUBLIC_ORIGIN`: адрес настроенного HTTPS-поддомена проходит origin-проверку; чужие источники по-прежнему отклоняются. Без настройки сохраняется локальный origin.
- Linux использует установленный или управляемый Playwright Chromium. Для входа предусмотрен виртуальный экран с noVNC, доступный через защищённый nginx.
- `TINVEST_DATA_DIR` отделяет токены, историю и профиль браузера от кода; systemd запускает бот от отдельного пользователя с правами файлов 0600.
- Точная причина ошибки клиента на его устройстве ещё не установлена. Нужны текст ошибки или вывод диагностики; работа на ПК разработчика не доказывает доступность API на клиентском ПК/VPS.
- Поле `relativeYield` теперь сохраняется и самим адаптером истории Пульса; порог 0,15% по-прежнему не реализован.
