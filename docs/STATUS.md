## Авторизация и источники

Мониторинг не использует T-Invest API: читает видимые сделки через внутренние запросы сайта Пульса в отдельном браузере. Для этого нужен обычный вход пользователя в Т-Банк в окне, которое открывает мониторинг. В существующий браузерный сеанс пользователя сервис не подключается. Cookie и данные входа остаются в `.local/pulse-browser/`; после успешного чтения cookie дополнительно сохраняются в `pulse-session.json` внутри этого исключённого из Git каталога. URL с `sessionId` держится только в памяти процесса и не выводится в интерфейс или лог. Ошибка закрытой вкладки больше не сбрасывает доступ к админке: монитор пробует восстановить сеанс в фоне.

T-Invest API понадобится для чтения собственного счёта и реальных покупок/продаж. Для реальных заявок нужен отдельный токен с соответствующими правами и правила риска. На этом этапе токен T-Invest не нужен.

Пульс скрывает объём чужой сделки; точное копирование количества невозможно по показанным данным. При истечении входа сервис показывает ошибку и ждёт повторного входа. Поскольку это внутренний веб-интерфейс, стабильность, допустимая частота и задержка публикации не гарантированы.

При живой проверке 03.10.2026 сохранённая сессия открыла админку без повторного видимого входа: получены 1745 уникальных инструментов LinMath и 16 операций за последние 24 часа. Запросы выполняются внутри браузера, где вход уже действует. Отдельный HTTP-клиент на этой машине отклонялся из-за цепочки сертификата. Количество инструментов и анализ совпали в двух последовательных опросах. Доставка Telegram по реальному токену, обнаружение новой сделки после публикации и ручная демо-покупка в UI ещё требуют отдельной проверки.
