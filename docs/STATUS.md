## Авторизация и источники

Мониторинг не использует T-Invest API: читает видимые сделки через внутренние запросы сайта Пульса в отдельном браузере. Для этого нужен обычный вход пользователя в Т-Банк в окне, которое открывает мониторинг. В существующий браузерный сеанс пользователя сервис не подключается. Cookie и данные входа остаются в `.local/pulse-browser/`; после успешного чтения cookie дополнительно сохраняются в `pulse-session.json` внутри этого исключённого из Git каталога. URL с `sessionId` держится только в памяти процесса и не выводится в интерфейс или лог. При проверке входа монитор переходит на сделки выбранного профиля в уже открытой вкладке, даже если Т-Банк оставил пользователя на другой странице. Админка, настройки и ручной демо-сценарий доступны при отключённом Пульсе.

На Windows видимое окно банка требует запуска админки из интерактивной консоли пользователя через `start_admin.cmd`. При запуске сервера фоновым инструментом окно Brave может оказаться недоступным на рабочем столе, хотя процесс работает. Одновременно на порту 8765 допускается только одна копия сервера.

Для чтения собственного счёта добавлено подключение T-Invest API по токену с правом «только чтение». После проверки токена пользователь выбирает счёт; админка показывает доступные рубли, общую стоимость портфеля, позиции и заблокированное количество. Подключение не зависит от Пульса. Токен и выбранный счёт хранятся локально в исключённой из Git `.local/`. Токены с полным доступом к доступным счетам отклоняются. Доступ на реальном счёте ещё не проверен, поскольку токен владелец не предоставлял. Для реальных заявок понадобятся отдельный этап, проверка лотов/ГО, согласованные правила риска и отдельное разрешение владельца; в текущей версии методов выставления заявок нет.

Пульс скрывает объём чужой сделки; точное копирование количества невозможно по показанным данным. При истечении входа сервис показывает ошибку и ждёт повторного входа. Поскольку это внутренний веб-интерфейс, стабильность, допустимая частота и задержка публикации не гарантированы.

При живой проверке 03.10.2026 сохранённая сессия открыла админку без повторного видимого входа: получены 1745 уникальных инструментов LinMath и 16 операций за последние 24 часа. Запросы выполняются внутри браузера, где вход уже действует. Отдельный HTTP-клиент на этой машине отклонялся из-за цепочки сертификата. Количество инструментов и анализ совпали в двух последовательных опросах. Владелец проекта дополнительно сообщил, что 03.10.2026 проверил работу Пульса и доставку Telegram. Обнаружение **новой** сделки после публикации и ручная демо-покупка в UI ещё требуют отдельной проверки.

Фоновая проверка 04.10.2026 с сохранённым локальным профилем не получила ответов API Пульса (`0` наблюдаемых запросов). Это результат **фонового** запуска; он не опровергает успешную проверку владельца в видимом окне 03.10.2026. Новых видимых окон фоновая проверка не открывала. Демо-сценарии и настройки работают без Пульса. Алгоритм демо-расчёта и HTTP-сценарии проверены автоматическими тестами; новая кнопка «Проверить отправку» после изменения кода ещё не проверялась с реальным токеном и ID.
