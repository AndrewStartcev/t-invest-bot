# Расширение Brave: источник сделок и авторизации Пульса

**Новая архитектура:** каждый клиент входит в Т-Банк в своём Brave, расширение
читает открытые страницы Пульса через его авторизованную веб-сессию, а сервер
принимает только данные об инструментах, опубликованных сделках и статусы
авторизации. **Серверный Playwright больше не запускается.**

## Где находятся данные

- Админка выбирает единственного отслеживаемого автора.
- Расширение с уникальным ключом кабинета загружает список инструментов
  выбранного автора (включая статистику и последнее время сделки).
- При первом полноценном чтении создаётся **исходный снимок счётчиков**.
  Старые операции не объявляются новыми и не отправляются в Telegram.
- При увеличении счётчиков расширение загружает новые операции, передаёт их
  серверу, который проверяет полноту прироста, сохраняет позиции счётчиков,
  показывает новые сделки в админке и при включённых уведомлениях отправляет
  информацию в Telegram. **Брокерские заявки не отправляются.**
- Сервер хранит по каждому клиенту собственный ключ, счётчики и события.
  Смена автора начинает новый снимок и не смешивает события.
- Проверка авторизации происходит через авторизованные запросы API Пульса
  в Brave, включая периодическую проверку профиля. При явной потере входа
  отправляется однократное уведомление. Если расширение пропадает более
  5 минут, сервер сообщает о потере связи.

## Как обновить

Перед обновлением рабочего сервера согласуй перезапуск и убедись,
что автоматическая реальная торговля **выключена**. Уже размещённые
брокерские заявки обновление не отменяет. В рабочем окружении не выполняй
команды без согласования.

```bash
cd /opt/t-invest-bot
git branch --show-current
git status --short
sudo bash scripts/update_server.sh
sudo bash scripts/enable_extension_route.sh invest.argokov.ru
```

Второй скрипт обновляет ровно виртуальный хост T-Invest Bot для отчётов
расширения размером до 2 МБ, сохраняет резервную копию и проверяет
`nginx -t` перед применением.

## Подключение клиента

1. Войди в свой кабинет `https://invest.argokov.ru/`.
2. Выбери отслеживаемого автора в настройках кабинета.
3. Открой **Обзор → Мониторинг** и нажми **Скачать расширение (.zip)**.
4. Распакуй ZIP на компьютере в постоянную папку.
5. Открой `brave://extensions/` → **Режим разработчика** →
   **Загрузить распакованное**; укажи папку `t-invest-pulse-extension`.
   Если расширение установлено раньше, обнови его через кнопку
   «Обновить» на странице расширений после замены файлов в папке.
6. Скопируй ключ из кабинета в расширение; укажи URL панели и логин
   **своего** кабинета, включи мониторинг. Автор в расширении не выбирается.
7. Нажми **Проверить связь**, затем **Войти в Пульс**. Авторизуйся в Т-Банке
   привычным способом, перейди на вкладку **Сделки** выбранного автора и
   нажми F5. Не закрывай вкладку.
8. После полного первого списка админка показывает число инструментов,
   затем новые сделки и дату отчёта. В журналах старые ошибки Playwright
   остаются только как архив; они не относятся к новому каналу.

## Технические ограничения

- Интервал 3–5 секунд — желаемая частота, а не гарантия. Большой список
  инструментов и фоновая вкладка увеличивают интервал и время первого снимка.
- Расширение опирается на внутренние API веб-версии банка. Изменение схемы
  ответов может потребовать обновления расширения.
- В первую синхронизацию передаются инструменты и счётчики; **старые сделки
  за предыдущие сутки не подгружаются автоматически**. Новые сделки после
  исходного снимка видны в админке. Полная архивная история требует отдельной
  процедуры загрузки, не путай её с потоком новых операций.
- Из банковского браузера не отправляются cookie, пароли, банковские
  токены, sessionId или служебные заголовки запросов. URL с sessionId
  используются только внутри браузера для повторения того же запроса.
- Сигналы расширения являются источником наблюдений, а **не сигналами к
  автоматическому выставлению реальных брокерских заявок**. Перед включением
  копирования понадобится живое тестирование и сверка с эталоном.

## Диагностика

- **Ожидаем первый снимок:** проверь включение расширения, ключ, правильного
  автора, открытую вкладку «Сделки» и обнови F5.
- **Не найден запрос инструмента:** банк не сделал ожидаемого API-запроса
  после установки расширения; попробуй снова открыть страницу Сделки.
- **Неполная история:** курсоры истории или большое количество новых
  операций требуют сверки; сервер не продвигает счётчики молча.
- **Требуется вход:** зайди в банк из того же Brave, не на сервере.
- **Нет связи:** держи браузер и вкладку открытыми. При выключении через
  кнопку расширения уведомление о потере связи не отправляется.
