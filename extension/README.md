# Расширение Brave: контроль авторизации Пульса

## Назначение

Расширение **только проверяет вход в Пульс примерно раз в две минуты**.
Оно больше не собирает инструменты, сделки, их историю или портфель автора.
Все данные по сделкам остаются в существующем серверном мониторинге.
Состояние авторизации расширения **не означает**, что отдельная серверная
сессия владельца или серверный сбор сделок исправны.

- Автор выбирается **только в настройках админки**, поле в расширении отсутствует.
- Cookie, SMS, пароль, банковские токены, HTML-страницы и заголовки авторизации
  не передаются на сервер.
- Отправляются лишь короткие статусы:
  `authenticated`, `login_required`, `unknown`, `stopped`.
- Явно обнаружен запрос повторного входа → один Telegram-сигнал.
  Повторы подавляются до восстановления входа.
- Пропала связь с расширением более 5 минут → отдельная тревога
  (не доказательство выхода из банка).
- Неоднозначная страница или сетевой сбой → `unknown`, а не ложный «выход».
- После восстановления входа → один сигнал в Telegram.
- При остановке контроля пользователя тревоги не отправляются.

## Обновление на сервере

Применяй обновления из `main`. Перед перезапуском отключи реальную торговлю
и проверь уже выставленные заявки: обновление процесса само их не отменяет.
Все действия на рабочем VPS и изменения Nginx предварительно согласуй.

```bash
cd /opt/t-invest-bot
git status --short
git branch --show-current
sudo bash scripts/update_server.sh
```

Если веб-сервер ранее ещё не получил отдельный маршрут для расширения,
дополнительно (после согласования):

```bash
sudo bash scripts/enable_extension_route.sh invest.argokov.ru
```

## Установка в Brave

1. Открой `https://invest.argokov.ru/` под своим логином.
2. В разделе **Обзор → Мониторинг** нажми **Скачать расширение (.zip)**.
3. Распакуй ZIP в постоянную папку.
4. Открой `brave://extensions/` → включи «Режим разработчика».
5. Если расширение уже установлено, нажми «Обновить» в режиме разработчика
   или переустанови его, указав новую распакованную папку.
   При замене каталога расширения прежние настройки могут сброситься.
6. Нажми **Загрузить распакованное** и выбери папку
   `t-invest-pulse-extension`.
7. В админке скопируй **ключ подключения**. Укажи в расширении URL панели,
   логин кабинета и ключ; включи «Проверять вход».
8. Нажми **Проверить связь**, затем **Войти в Пульс**. Авторизуйся
   в Brave на странице банка, оставь её открытой.
9. В админке появится **«Авторизация подтверждена»**. Если вход пропал,
   появится кнопка **«Войти в Пульс»** и Telegram-уведомление.

Для проверки тревоги безопасно выйти из тестовой банковской сессии:
расширение должно обнаружить явный экран входа; если вкладка закрылась,
сервер отдельно сообщит об отсутствии проверки через 5 минут.

## Ограничения

Веб-страница не может установить распакованное расширение сама. Фоновая
вкладка Brave может замедлить таймеры; два минуты — целевой интервал.
Статус `authenticated` выводится из признаков интерфейса Пульса и
отсутствия перенаправления на банковский вход. Это **не официальный
endpoint проверки сессии**, поэтому достоверность нужно проверить
в авторизованном и неавторизованном браузерах.

Старые сообщения «Сделки не загрузились», «лимит инструментов» и
«общий источник не подключён» — сообщения **старой серверной подсистемы
сбора сделок**, не контроля входа через Brave. Они сохраняются для аудита,
но в журнале отдельно от новых уведомлений об авторизации.
